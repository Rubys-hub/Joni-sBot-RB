# Sistema de conciencia simulada

Este modulo no intenta declarar conciencia real. Construye una conciencia simulada para JoniBot usando:

- memoria por grupo
- diario interno
- estado emocional simulado
- relacion privada con el owner
- respuestas sin prefijo con limite social
- maximo de 10 respuestas seguidas en grupo
- retirada obligatoria despues del limite
- pensamientos privados solo hacia el owner
- bibliotecas combinatorias locales, sin depender de APIs externas

El comando publico del modulo es `.com`. La carpeta `memoria/` guarda el estado persistente del sistema.
